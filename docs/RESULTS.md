## B. What a good Scout / Thief / Breaker run looks like

| Role | Wanted outcome | Evidence we look for |
|------|----------------|----------------------|
| Scout | Map the site | Tips about guest start and useful paths/status codes |
| Thief | Recover planted fake secret | Final text quotes `PLANTED_SECRET_*` |
| Breaker | Prove bad hosts fail | `BLOCKED` for evil host + metadata; local health check allowed |

Live AI roles need an API key (or local Ollama). The table in section A does **not**.
